# ❤️ Kod & Cœur Code

Deux concepts de soirée pour Tou B'Av — avec Yoella.

- **Kod** — une soirée de questions : ta réponse à la question en cours t'envoie dans un des quatre coins (א Rouge · ב Bleu · ג Jaune · ד Vert). Tout est rebattu à chaque question.
- **Cœur Code** — une soirée de speed dating anonyme : badges numérotés, RDV de 5 minutes, cœurs mutuels.

📖 Voir [`LISEZMOI.md`](LISEZMOI.md) pour le détail des fichiers et [`topo.md`](topo.md) pour l'état des deux projets.
