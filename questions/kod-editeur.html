Travailler à plusieurs, sans serveur

Cet éditeur fonctionne entièrement hors ligne. Rien n'est envoyé nulle part.

  1. Chacun ouvre ce fichier et clique Importer pour charger la dernière version de kod-questions.json
  2. Il modifie ce qu'il veut, puis clique Exporter JSON
  3. Il remet le fichier dans le dossier partagé (ou le commit sur le dépôt)

Une règle pour éviter les collisions : une seule personne édite à la fois, ou chacun sur des questions différentes. Sans serveur, le dernier qui exporte écrase les autres.
